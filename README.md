# Event Ticketing System
A desktop-based Event Ticketing System developed using **C# Windows Forms**. The application allows administrators to manage events and users, while members can browse events, purchase tickets, and view their booking history.

---

## Features

- User authentication and login
- Administrator and Member user roles
- Event management
- User management
- Ticket booking
- Booking history
- Exception handling

---

## Technologies Used

- C#
- Windows Forms
- .NET Framework
- Object-Oriented Programming (OOP)
- Visual Studio

---

## Skills Demonstrated

- Object-Oriented Programming
- Encapsulation
- Inheritance
- Interfaces
- Exception Handling
- GUI Development
